## ✨ المميزات الرئيسية

### 1. تحليل المشاعر 🎭
- تصنيف المراجعات إلى 3 مستويات في المسار السريع و5 مستويات في التحليل المعمق للمنتجات
- دقة تقييم تصل إلى **94%** باستخدام النماذج المدربة (SVM, Random Forest, Logistic Regression) على بيانات الاختبار
- دعم كامل للهجة المصرية العامية

### 2. تحليل منتجات أمازون 🛒
- تحليل شامل لمراجعات أي منتج
- عرض السعر الحالي والخصومات
- استخراج المواصفات التقنية
- إحصائيات توزيع المشاعر

### 3. التحقق الذكي ✅
- رفض الروابط غير الصالحة
- رفض النصوص غير المفهومة
- رسائل خطأ واضحة وودية

### 4. واجهة مستخدم عصرية 🎨
- تصميم داكن احترافي
- دعم كامل للغة العربية (RTL)
- متجاوب مع جميع الشاشات

## 🚀 تشغيل المشروع

### الطريقة السريعة (نسخ ولصق)
```bash
# 1. تثبيت المكتبات
pip install -r requirements.txt
cd api && npm install

# 2. بناء وتشغيل
npm run build && npm start

# 3. افتح المتصفح
# http://localhost:3000
```

### خطوة بخطوة
1. افتح Terminal/CMD في مجلد المشروع
2. نفذ: `pip install -r requirements.txt`
3. نفذ: `cd api`
4. نفذ: `npm install`
5. نفذ: `npm run build`
6. نفذ: `npm start`
7. افتح المتصفح على: `http://localhost:3000`

## 🔌 واجهة برمجة التطبيقات (API)

### Endpoints المتاحة

| Endpoint | Method | الوصف |
|----------|--------|-------|
| `/api/health` | GET | فحص صحة النظام |
| `/api/sentiment/analyze` | POST | تحليل مراجعة واحدة |
| `/api/product/analyze` | POST | تحليل منتج كامل |
| `/api/product/info` | POST | معلومات المنتج |

### مثال: تحليل مراجعة
```bash
curl -X POST http://localhost:3000/api/sentiment/analyze \
  -H "Content-Type: application/json" \
  -d '{"text":"المنتج ده جامد أوي"}'
```

**الاستجابة:**
```json
{
  "success": true,
  "data": {
    "sentiment": "positive",
    "confidence": 0.92
  }
}
```

## ✅ اختبار المشروع

### اختبار 1: تحليل مراجعة إيجابية
- **الإدخال**: `المنتج ده جامد أوي والجودة ممتازة`
- **النتيجة المتوقعة**: Positive ✅

### اختبار 2: تحليل مراجعة سلبية
- **الإدخال**: `المنتج وحش وخايب ومش يستاهل`
- **النتيجة المتوقعة**: Negative ✅

### اختبار 3: تحليل مراجعة محايدة
- **الإدخال**: `المنتج كويس بس فيه مشاكل في التغليف`
- **النتيجة المتوقعة**: Neutral ✅

### اختبار 4: رفض نص غير صالح
- **الإدخال**: `محمد`
- **النتيجة المتوقعة**: رسالة خطأ ودية ✅

### اختبار 5: رفض رابط غير صالح
- **الإدخال**: `https://google.com`
- **النتيجة المتوقعة**: رسالة "الرابط مش من أمازون" ✅
